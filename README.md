Frappe and ERPNext are more than frameworks I use — they are the core of my professional development experience.

### What I build

| Area | Experience |
|---|---|
| Custom Applications | Frappe custom apps, DocTypes, fields, forms, and business logic |
| Document Lifecycle | Validation, hooks, document events, and controller-level troubleshooting |
| ERPNext Workflows | Sales, purchasing, inventory, accounting, and operational processes |
| Integrations | REST APIs, external services, data synchronization, and custom endpoints |
| Reports & Data | Query reports, Script Reports, data exports, and SQL optimization |
| Permissions | Role permissions, User Permissions, document access, and query filters |
| GST & Compliance | India-specific ERP workflows, GST-related calculations, and e-Invoice troubleshooting |
| Automation | Scheduled jobs, background tasks, notifications, and repetitive process automation |
| Production Support | Root-cause analysis, debugging, data validation, and performance troubleshooting |
| Deployment & Operations | Linux servers, bench management, application deployment, and troubleshooting |

### How I approach ERP problems

```text
Business Requirement
        ↓
ERPNext Workflow Analysis
        ↓
Frappe Document Lifecycle
        ↓
Custom Business Logic / API Integration
        ↓
Testing & Data Validation
        ↓
Production Deployment & Monitoring
```

I focus on understanding the underlying business process, identifying the actual root cause, and implementing a solution that works reliably in production.
